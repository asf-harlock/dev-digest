### Deviations
1. **KPI cards use my own `KpiCard`, not the kit `MetricCard`.** `MetricCard` prints the delta as `Math.abs(delta).toFixed(2)`, which gives "4.00" where the spec wants "4 pt". Its sparkline can't take null either.
2. **Sparklines use `GapSparkline`.** Series with no gap and two or more points use the kit `Sparkline` unchanged; anything with a null or a single point is drawn by my own SVG, because the kit one can't leave gaps.
3. **The Metric trend is a hand-rolled SVG, not the kit `LineChart`.**
   - `LineChart` turns null into 0, which violates EC-36.
   - It also fixes the y-range to 0.6–1.0, which would clip low scores.
   - Mine uses a 0–100% y-axis, labels `v{n}` on x (at most 10 labels), and gives each series a different dash so the lines don't rely on colour alone.
4. **Dashboard table has a Status column**, using the existing `dashboard.table.status` key. The spec's column list doesn't include it. It is additive and lets a running or errored row read as such instead of all "—".
5. **Vendored `Modal` has no accessible name.** It has no `aria-labelledby`, and I can't edit vendor. `useModalA11y` adds Escape, focus-in and focus-return. There is no focus trap; Tab can leave the dialog.
6. **The agent dropdown is the kit `Dropdown`**, which has no Escape or arrow-key handling.
